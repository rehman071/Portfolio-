## Overview

A single-file, luxury editorial portfolio designed around an alternating **Midnight Obsidian**, **Warm Alabaster Silk**, and **Champagne Gold** visual system. Built to showcase engineering craft, web architecture, and visual storytelling without visual clutter—combining static portrait framing, live embedded project previews, interactive 3D particle geometry, and accessible motion controls.

---

## Key Features

- **Editorial Hero & Static Portrait Stage (`01 / PRESENCE`):** High-contrast typographic hierarchy paired with a seamless obsidian-blended portrait, direct navigation links, and a global **`MOTION ON / OFF`** toggle for reduced-motion control.
- **Interactive 3D Perspective Stage (`01 / ABOUT`):** Custom HTML5 Canvas particle system that morphs dynamically across three core perspectives—**Intelligence**, **Structure**, and **Rhythm**.
- **Live Interface Work Showcase (`02 / SELECTED WORK`):** Embedded browser-frame previews with interactive/preview mode toggles, live deployment links, and a slide-over **Case Study Drawer**.
- **Box-Free Disciplines Index (`03 / DISCIPLINES`):** Hairline-separated capability ledger with category filtering and minimalist 5-diamond gauges covering **AI Engineering**, **Web Design & Building**, and **Freelance Video Editing**.
- **Education Ledger (`04 / EDUCATION`):** Structured academic timeline with clean editorial typography.
- **Direct Concierge Contact (`05 / CONTACT`):** One-click copy actions for email and phone along with verified social links.
- **Kinetic Micro-Interactions:** Subtle character-scramble hover effects on navigation and primary call-to-action controls, fully responsive across desktop and mobile screens.

## Running Locally

Since the portfolio is built as a self-contained static web project, no build step or package installation is required:

```bash

# 2. Navigate into the project directory
cd <your-repo-name>

# 3. Open index.html directly in your browser
# Or serve locally using any lightweight static server:
npx serve .
